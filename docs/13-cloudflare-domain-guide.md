# Подключение домена в Cloudflare

Пошаговая инструкция доступна после авторизации во вкладке **Документация**:
https://domain-router.tail6ace7f.ts.net/docs

Единый исходник, который поставляется вместе с приложением и отображается в админке:
[Инструкция Cloudflare](../src/domain_router_ui/help/cloudflare.md).

Описаны подключение зоны, смена NS, DNSSEC, CNAME в существующий Tunnel,
серверный список разрешённых зон, маршруты, HTTPS и диагностика.

Инструкция не содержит UUID конкретной установки. Актуальный DNS Target
вычисляется из действующей конфигурации во вкладке **Подключения → Cloudflare Tunnel**
и копируется кнопкой. После замены Tunnel обновите DNS-записи, а не документацию.
UUID не является секретом; credentials JSON, cert.pem и токены в документацию не входят.

Серверная обёртка для старых установок находится в
`config/domain-router-wrapper`; инструкция объясняет её установку перед
использованием `/etc/domain-router/environment`. Обновление документации само по
себе не меняет список доменов, DNS или существующие маршруты.
