# Аудит Репозитория: 2026-10-10

## Вывод

Репозиторий содержит код админки, CLI, агентов и сценарии восстановления
инфраструктуры. После исправлений порядок восстановления, обновления и границы
автоматизации описаны в документе [08](08-rebuild-from-zero.md), а для Codex
зафиксированы в [CODEX.md](../CODEX.md). Это не образ всего сервера: прикладные
диски, медиа, аккаунты и секреты восстанавливаются отдельно.

## Что Воспроизводится

- CT 100: сеть, NAT, Caddy, Cloudflare connector, CLI и приватная админка.
- Ubuntu Server 24.04 VM 101: чистая ОС и ресурсы, не содержимое production-приложения.
- Proxmox Tailscale и специализированный NIC watchdog для текущего Intel/e1000e.
- AdGuard CT 106, фильтры и DNS-настройки; изменение DHCP роутера выполняется отдельно.
- CT 107, вторичные адреса уже установленных сервисов, trusted networks и firewall.
- Реестр сервисов, переключатели, документация и управление подключениями в UI.

## Проверки Перед Публикацией

```sh
python -m pytest
python scripts/check-repository.py --history
git diff --check
```

Полный локальный набор: 64 теста. Проверены синтаксис всех Bash-скриптов,
Python и JavaScript, состав wheel (шаблоны, help, SVG/JS/CSS, лицензия Lucide),
упаковка исходников и отсутствие runtime state в архиве.

Проверка исходников и всей достижимой истории Git не выявила типовых Tailscale,
Cloudflare/GitHub tokens, PEM private keys и credential JSON. Дополнительно
проверены известные использованные пароли без включения их значений в отчёт.
Это pattern scan и ручная проверка состава, не математическая гарантия отсутствия
любых возможных секретов. Публичные домены, private IP и Tunnel UUID не являются
ключами доступа. Не публикуйте account credentials и Tailscale state.

GitHub CI настроен на Python 3.11/3.13; его фактический результат смотрите в
Actions после push. Локальные тесты выполнены на Python 3.14. Изменения этого
аудита не применялись к production и не запускали создание/перезапуск гостей.
Предыдущая интеграция отдельно прошла live smoke checks, apply/rollback Tunnel
и независимый аварийный таймер; это не повторный destructive rebuild.

## Оставшиеся Ограничения

- Чистый end-to-end rebuild на отдельном пустом Proxmox в ходе аудита не выполнялся.
  Для полной проверки воспроизводимости нужен второй хост или отдельная тестовая среда.
- VM 102/103 и CT 104/105, их приложения и данные требуют собственных backups.
  Репозиторий не содержит установщиков Home Assistant, Meshtastic, Jellyfin и TorrServer.
- Cloudflare/Tailscale account login, NS/DNS, route approval, ACL и key expiry
  требуют участия владельца. Обновление DNS не производится самой админкой.
- Advanced agents фиксируют CT 100/107, private /24 и текущую LAN. Для другой
  топологии нужен согласованный перенос; `.env` не меняет все эти значения.
- Debian template проверяется по наличию на хосте; версии Ubuntu image,
  cloudflared, Tailscale и Python dependencies не полностью закреплены.
  Это процедурная воспроизводимость, не byte-for-byte build. Сохраняйте
  проверенные backups/образы и сверяйте версии перед обновлением.
- AdGuard DNS является единственной точкой отказа домашнего DNS. LAN-исключение
  HA и LAN-only сервисы не переносятся в другую подсеть автоматически.
- `content-factory-vps.win` ранее давал 404; актуальные маршруты используют
  `content-factory.win`, `www.content-factory.win` и `mesh-kremen.stream`.
  Наличие DNS/Tunnel не означает готовность приложения: проверяйте каждый сайт.
- Генерируемые пароли выводятся установщиками один раз. Не сохраняйте terminal
  transcripts в Git; для AdGuard начальная настройка передаёт пароль локальным
  install/API-командам. Работайте на доверенном Proxmox и затем смените пароль.
